Output

Load the Proj vs SO file and the fill rate to see the output.

Groups

One row per output row, in this order. Proj vs SO Groups take SO Qty through the mapping below. Fill Rate Groups sum Stock Qty in KGS over the rows that match every filled column; a cell with several values separated by commas matches any of them. In Item Name contains, a number such as 16 or 16 g is a pack size, so 160 g does not count as 16 g; other text is a plain “contains”. A Fill Rate Group with no filters is 0.

Proj vs SO mapping

A Proj vs SO row counts towards the Group when its Item Group or item_parent equals the Value. A Group with several mapping rows counts each Proj vs SO row once, even if it matches more than one.
