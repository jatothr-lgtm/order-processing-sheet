Master

Three tables decide the output. Normalisations clean the values in the files first; Groups and the Proj vs SO mapping then decide what each output row sums. Edits apply at once and are kept in this browser.

Each table also has its own Export, Import file and Paste rows. An import shows what will change and lets you Add & update (new rows are added, rows already there are updated) or Replace all. Every output file carries the master it was built with and can be uploaded here.

Normalisations

Replaces a value in one column of one file before any rule sees it: a spelling variant, a renamed item, an old name. Case and extra spaces are always ignored, so “Trail mix” and “Trail Mix ” need no row. The raw value must match the whole cell. Each value is replaced once; normalisations do not chain. Changed counts the lines each row rewrote in the files loaded; 0 means it matches nothing there.

Groups

One row per output row, in this order. Proj vs SO Groups take SO Qty through the mapping below. Fill Rate Groups sum Stock Qty in KGS over the rows that match every filled column; a cell with several values separated by commas matches any of them. In Item Name contains, a number such as 16 or 16 g is a pack size, so 160 g does not count as 16 g; other text is a plain “contains”. A Fill Rate Group with no filters is 0. Import matches Groups by name.

Proj vs SO mapping

A Proj vs SO row counts towards the Group when its Item Group or item_parent equals the Value. A Group with several mapping rows counts each Proj vs SO row once, even if it matches more than one.
